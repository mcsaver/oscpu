# R3 物理结果：局部输入锥改善，全局未达到联合目标

本轮组合候选改善了 event/RR、effect、mem_issued 和 CQ 输入的多条路径，也产生了新的 CQ→RR/Issue 路径；但标准全局 setup WNS 退化 7.698297 ps，最终可比面积增加 0.557146%，1 ns 下两版正式判断均为 FAIL。按本轮预设联合目标，物理证据不支持保留 R3。功能与程序周期结果见主报告；不能用程序周期降低抵消本轮约定的时序条件。

## 比较对象与测量口径

- B：上一轮保留版本，`results/ai-architecture-20261008/mapped-export-recovery/candidate`。R3：`results/ai-r3-20261008/candidate-sta/R64SystemTop-1000MHz`，标准流程使用冻结的 `build/ai-r3-20261008/candidate-vsrc`。
- 同一 OpenSTA 3.1.0、icsprout55 TT 1.2 V 25°C Liberty、原 1 ns SDC。SDC、工具、Liberty 和加载脚本 SHA-256 已逐项相同；未改变 input delay、uncertainty、reset 检查或任何例外。所有全局报告保留输入/reset；Q-only 是附加视图。
- 这是 mapped pre-layout STA，保留真实库 ICG 检查，没有提取布局布线寄生。静态可达不等于已证明功能可激活；这些数据不能当成最终 Fmax。
- 本次为组合候选实测，没有各功能开关的独立综合消融。路径差异可以定位测量中的延迟变化，不能把它自动归因于某一项 RTL 改动。

## 同一 state 位的完整路径对照

B 实际最差链：`rst_i → full_flush → ROB cancel_candidates[15] → execute.lsu_fire[1] → LSU state_q[18][2] D`。R3 实际最差链：`rst_i → full_flush → ROB cancel_candidates[9] → execute.lsu_fire[1] → LSU state_q[18][2] D`。两条路径的前段分支不同，下面每列都来自该版本这一条连续实际路径，没有拼接多个路径的阶段最大值。

R3 的 lsu_fire[1] 在这两条路径上反而早 151.921749 ps，但之后到 state D 的尾段增加 423.949956 ps。尾段逐点 cell 增量求和为 B 0.546298125 ns、R3 0.970248134 ns，reported net 增量都为 0；微小差额来自工具浮点及逐点打印舍入。这里的零 net 增量属于未提取互连的模型，不能理解为真实布线零延迟。full_flush 驱动 fanout 为 87→92、cap 为 0.074117251→0.079914354 pF、slew 为 0.794148684→0.855817556 ns。

这证明同位时序发生了实际退化，同时指出当前最差路径中的后段代价；并未证明一个孤立 RTL 改动就是原因。完整每个 cell/input-pin/net 增量、slew、负载、fanout 见文末证据和附录。

## 执行完整性与证据

- 标准 `make sta` 返回 2，原因是原 timing checker 的真实 FAIL；综合网表 CHECK 0 problems，OpenSTA 正常完成。标准全过程 `/usr/bin/time` 峰值 RSS 9,268,600 KiB，未使用不足的 6 GiB cap。
- 候选补充 OpenSTA 返回 0，52 个扩展 query，加既定 7 个 CQ/raw all/Q 组、flush-through、CQ→WB 与全部负 hold；运行记录 800.139529 s，`/usr/bin/time` wall 13:28.72，峰值 RSS 3,877,352 KiB。输入身份前后完全一致。
- B 旧结果复用；新增参照 32 query 已完成，补充 state 族与同 bit 两组又一次有界分析 31.040914 s、rc0，全局值完全不变。没有重综合、重映射或新增设计点。
- 两次只在候选准备阶段失败：严格旧组集合需要显式加入 cq_ticket；优化后的 short-owner 公共别名需核对真实连接。失败目录保留，均未启动 EDA。末尾详细解析遇到合法空 checks JSON 后只修复空集合处理并重跑解析，STA 没有重跑；原失败日志与解析恢复日志保留。
- 所有路径对象均在该次 query 内立即转成不可变字段，不跨后续 timing query 保存 OpenSTA PathEnd。
