# 零误差验收

用户要求：在相同 RTL 配置、镜像、外部输入、复位方式和统计区间下，周期数完全相等。
本目录的 trace 时序模型尚未达到这个要求。不能用平均误差阈值或 CPI 四舍五入替代该标准。

## 比较范围

- 同一条动态退休指令流，指令数完全相等。
- 从复位后 cycle 0 开始，每条指令的绝对退休周期完全相等，包括首条退休。
- 双退休的两条指令分别比较，可具有相同的周期值。
- 完整运行必须自然到达测试程序的成功终止；周期上限前缀仅说明该前缀。
- 两个完整执行后端还需比较终止事件所在周期，覆盖最后一条退休到 EBREAK 响应的尾部。
- ISA 功能正确性继续由原有 NEMU DiffTest、CSR/寄存器/设备检查及 RTL 断言负责。
  时序比较不能替代功能验证。

原有验证程序在完成 5 个复位时钟后以 cycle 0 运行第一拍，
verbose 退休日志与终止 PASS 使用这个周期编号。比较不做起点平移、不扣除冷缓存开销、
不加拟合常量。若按完整运行的拍数计算，终止周期编号加 1；双方必须使用同一约定。

## 工具

手写 trace 模型与 RTL 同流对照：

    python3 npc/rv64/model/compare.py \
      --trace RUN/functional.trace --rtl-cycles RUN/rtl.cycles \
      --stages RUN/stages.csv --require-exact

逐条绝对周期存在偏差、或者未自然结束时返回 2。
显式添加 --allow-prefix 可以验收有限前缀，报告仍注明不完整。
不指定 --require-exact 时仅输出诊断数值，进程正常结束不表示时序验收通过。

两个独立执行后端分别通过 collect_rtl.py 采集后：

    python3 npc/rv64/model/compare_runs.py REFERENCE_RUN CANDIDATE_RUN

该命令比较退休流记录、每条绝对退休周期以及成功终止周期；
任一不一致返回 2。记录中的操作数与地址也参与比较。
两边必须使用同一镜像与环境；不能用一份记录复制出来当作独立执行证据。

## 当前误差来源

2026-09-17 的结构修正包括较老未完成翻译 load 的屏障、
直接/延后 LSU 查询通路、完成端口轮转和 DIV 状态机拍数。
同流 CoreMark 前缀的退休跨度误差从 v0.1 的 -23.30% 降至 -2.85%，
同流 Dhrystone 前缀仍为 -7.28%。两个前缀均未通过零误差验收。

完整 CoreMark 对照也已经完成：原有 SystemTestTop + NEMU DiffTest 自然通过，
退休指令数为 3,218,524，终止周期编号为 9,241,964。
同一条 RTL 动态指令流的首末退休跨度为 9,241,910 拍，手写模型为 8,830,708 拍，
低估 4.4493%，最大逐指令周期偏差为 411,232 拍。
该完整运行同样未通过零误差验收。

完整 Dhrystone 对照也已自然结束且通过原有 DiffTest：
退休指令数为 4,260,670，终止周期编号为 14,568,135。
同流 RTL 首末退休跨度为 14,568,081 拍，手写模型为 13,435,922 拍，
低估 7.7715%，最大逐指令周期偏差为 1,132,162 拍。
两份完整对照在第 5 条动态指令即出现第一次偏差：RTL 为 cycle 106，模型为 cycle 70。
因此它们不是仅在收尾或统计口径上不一致。

剩余缺口涉及实际状态，而非统一延迟系数：

- 正确路径轨迹不包含被 squash 的指令、推测地址和它们产生的资源及缓存占用。
- FetchStream 早期目标表、预测器、重取与恢复需要维护真实的逐拍状态。
- I/D 缓存填充通过平台仲裁发生交错，不能用串行固定 miss 延迟替代。
- LSU 各类 owner、描述符、查询、转发与完成队列的时序仍有聚合抽象。

因此手写模型只能用于带误差说明的探索，不能输出“与 RTL 一致”的结论。
从 RTL 自动生成 C++ 周期模型是一条正在实验的路线；通过代码生成本身不证明零误差，
也不证明比 Verilator 更快，必须在相同程序和检查条件下实测。

CXXRTL 部分优化构建现已在 compressed 微基准中独立执行并通过 DiffTest：
195 条退休指令的全部绝对周期与终止周期 302 均一致。该用例主机耗时 16.99 秒，
原 Verilator 记录为 0.164 秒，因此它还不是满足加速目标的实现。
另外，load_banks（259 条指令，结束周期 610）和 divide（68 条指令，结束周期 784）
也通过了相同的逐条零误差检查。
这些有限用例不能扩展为全核、完整基准或全部配置的零误差结论，细节见 CXXRTL.md。
